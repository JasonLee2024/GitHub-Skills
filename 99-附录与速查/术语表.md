# 文档编写规范

## Frontmatter 模板

```yaml
---
date: 2026-05-05
tags:
  - tag1
  - tag2
  - category
source_skill: skill-name
category: 章节中文名
---
```

## 中文文档编写指南

1. **内容要求**
   - 全中文撰写（面向中国开发者）
   - 代码注释和命令示例保持英文
   - 专业术语首次出现时标注英文
   - 每文件 ≥ 150 行

2. **交叉引用**
   - 使用 `[[双链]]` 语法引用本库其他文档
   - 使用 `[[本库其他文档#小节名|显示文字]]` 引用特定小节
   - 对于外部链接，使用 `[描述](url)` 标准 Markdown

3. **章节结构**
   - `_index.md` 作为章节索引，引用本文件夹下所有 `.md` 文件
   - 内容文档按照 `NN-英文slug.md` 格式命名
   - 每个章节用编号前缀维持排序（01-, 02-, ...）

4. **版本管理**
   - 日期使用 `YYYY-MM-DD` 格式
   - 重大更新时更新 date 字段
   - 过时内容标记 `tags: [outdated]`
